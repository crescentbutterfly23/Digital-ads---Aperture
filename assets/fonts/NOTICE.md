# Fonts in this repository

Both families are subset (Latin plus the punctuation the ad copy uses) and embedded in each
ad unit as base64 woff2. The `.ttf` copies are used only by the backup-still renderer.

| File | Family | Licence |
|---|---|---|
| `playfair-display-500.*` | Playfair Display, weight 500 | SIL Open Font License 1.1 |
| `archivo-300.*`, `archivo-500.*` | Archivo, weights 300 and 500 | SIL Open Font License 1.1 |

The SIL OFL 1.1 permits embedding and redistribution, including in a bundled document,
provided the fonts are not sold on their own and the licence travels with them.

Full licence text and the originals:

- Playfair Display — https://fonts.google.com/specimen/Playfair+Display
- Archivo — https://fonts.google.com/specimen/Archivo
- OFL 1.1 — https://openfontlicense.org

Archivo is the Aperture sans; Playfair Display is the display serif. Do not substitute
another sans.
